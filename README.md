# Парсер игровых каналов YouTube и Twitch

Ищет игровые каналы и стримеров по числу подписчиков, вытаскивает контакты из описания
(почта, Telegram, VK, Discord и другие ссылки) и сохраняет всё в Excel.
Без API-ключей, без авторизации и без нейросетей.

## Запуск

```bash
pip install -r requirements.txt
python parser.py --min-subs 5000 --max-subs 200000 --limit 100 --minutes 15
```

Или просто `python parser.py` без параметров: программа спросит платформы, подписчиков,
количество каналов, лимит времени и имя файла (Enter оставляет значение по умолчанию).

Работает, пока не найдёт `--limit` каналов или не истечёт `--minutes`, потом сохраняет `channels.xlsx`
и сама открывает его в Excel (`--no-open`, чтобы не открывать). Время делится между платформами поровну.
Ctrl+C останавливает поиск и сохраняет то, что уже найдено.

## Основные параметры

| Параметр | Что делает |
|---|---|
| `--platforms youtube,twitch` | где искать (можно одну платформу) |
| `--min-subs`, `--max-subs` | диапазон подписчиков или фолловеров |
| `--limit` | сколько каналов нужно на каждой платформе |
| `--minutes` | лимит времени |
| `--queries` | поисковые запросы YouTube (по умолчанию набор игровых) |
| `--games` | категории Twitch, например `--games "Minecraft" "Dota 2"` (по умолчанию топ игровых) |
| `--lang ru` | язык стримов Twitch |
| `--no-require-contact` | брать и каналы без контактов |
| `--no-views` | не считать средние просмотры YouTube (быстрее) |
| `--out` | имя Excel-файла |

## Что в таблице

Платформа, название, ссылка, подписчики, средние просмотры (YouTube: по последним 10 видео,
Twitch: зрители текущего стрима), почта, Telegram, VK, другие контакты, описание канала.

Twitch отдаёт только тех, кто сейчас в эфире, поэтому повторные запуски в разное время
находят новых стримеров.
